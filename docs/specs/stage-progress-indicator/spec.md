# 7단계 스테이지 진행 인디케이터 가이드

## 사용자 결과

초등학교 5학년 학습자와 옆에서 지켜보는 보호자가 3D 큐브 가이드 화면 상단에 있는 **1부터 7까지의 스테이지형 스텝 인디케이터(진행 바)**를 통해, 전체 7단계 중 지금 몇 단계를 맞추고 있고 완성까지 몇 단계가 남았는지를 한눈에 직관적으로 파악한다. 단계를 하나씩 마칠 때마다 체크 표시가 채워지며 게임 퀘스트를 깨나가는 듯한 성취감을 느낀다.

## 승인된 범위

- **스테이지형 7단계 스텝 인디케이터 바**:
  - 3D 큐브 가이드 화면 상단(단계 배지 및 제목 영역)에 1부터 7까지 일렬로 연결된 원형 스텝 바 배치
  - **완료된 단계 (1 ~ 현재단계-1)**: 초록색/강조색의 완료 체크(`✓`) 아이콘으로 성공 표시
  - **현재 진행 단계**: 돋보이는 강조 배지(프라이머리 배경, 굵은 숫자, 링 강조)
  - **남은 단계 (현재단계+1 ~ 7)**: 연한 회색의 대기 상태 숫자(`4`, `5`, `6`, `7`)
- **오조작 방지 읽기 전용 설계**:
  - 스텝 인디케이터는 순수 진행 현황을 알려주는 읽기 전용 컴포넌트로 동작
  - 아이가 큐브를 돌리거나 화면을 터치하다 스텝을 실수로 눌러도 단계가 엉키거나 페이지가 튀지 않음 (단계 건너뛰기는 하단의 전용 `[다음 단계로 건너뛰기]` 버튼이 안전하게 담당)
- **반응형 콤팩트 레이아웃**:
  - 가로 폭이 좁은 모바일 스마트폰 화면(360px 등)에서도 7개 스텝과 연결선이 잘리거나 겹치지 않고 한 줄에 쏙 들어가도록 컴팩트한 간격과 원 크기(지름 약 24~26px) 적용
  - 우측 상단의 `글자 [ − ] [ + ]`, `큐브 [ − ] [ + ]` 크기 조절 바와 조화롭게 정렬
- **최종 완성 상태 대응**:
  - 7단계까지 모두 맞추어 "축하합니다! 3x3 큐브를 모두 완성했어요!" 화면에 도달하면 1부터 7까지 모든 스텝이 기분 좋은 완료 체크(`✓`)로 가득 참

## 수용 기준

1. 3D 큐브 가이드 화면 상단에 1단계부터 7단계까지의 스텝 인디케이터가 항상 표시된다.
2. 현재 진행 중인 단계의 원형 배지가 다른 스텝과 명확하게 구별되도록 강조 표시된다.
3. 이미 완료한 이전 단계들은 완료 체크(`✓`) 아이콘으로 표시된다.
4. 아직 도달하지 않은 다음 단계들은 연한 색상의 숫자로 표시된다.
5. '다음 동작'을 진행하여 단계가 넘어가거나 '다음 단계로 건너뛰기'를 누르면 스텝 인디케이터가 즉시 해당 단계 위치로 갱신된다.
6. 7단계를 마치고 최종 완성 화면이 되면 1단계부터 7단계까지 모든 스텝이 완료(`✓`) 상태로 표시된다.
7. 스텝 인디케이터는 읽기 전용으로, 터치나 클릭 시 현재 단계나 큐브 상태가 변경되지 않는다.
8. 좁은 모바일 화면(360px)에서도 7개 스텝이 줄바꿈 없이 한 줄에 안정적으로 표시된다.

## 확정된 제약

- 색칠(색 입력) 화면에서는 아직 풀이가 시작되지 않았으므로 노출하지 않고, [큐브 맞추기 시작] 버튼을 누른 후 가이드 화면에서 표시된다.
- 큐브의 3D 렌더링 성능이나 큐브 조작 제스처(드래그) 영역을 가리지 않도록 상단 헤더 영역 내에 깔끔하게 배치한다.
- 임의 단계 점프는 학습 순서와 큐브 상태를 꼬이게 만들 수 있으므로 지원하지 않는다.

## 가정

- 1부터 7까지의 연결된 원형 스텝 표시는 별도의 설명 없이도 아이와 보호자가 '현재 위치'와 '전체 여정'을 직관적으로 이해할 수 있다.

## 범위 밖

- 특정 단계를 클릭하여 강제로 해당 단계의 큐브 상태로 롤백하거나 스킵하는 임의 내비게이션 기능.

## 미룬 지점

- 추후 각 스텝 위에 마우스를 올리거나 가볍게 터치했을 때 단계의 간단한 이름("2단계: 흰 면")을 미니 툴팁으로 띄워주는 보조 기능 여부.

## 남은 위험

- 모바일 화면에서 스텝 크기가 너무 작으면 손가락이나 시인성이 떨어질 수 있고, 너무 크면 가로 폭을 넘칠 수 있으므로 모바일 기준 최적 크기(24~26px)와 패딩 조절이 중요하다.
