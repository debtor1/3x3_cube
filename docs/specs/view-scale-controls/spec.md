# 폰트 및 큐브 크기 개별 조절 가이드

## 사용자 결과

초등학교 5학년 학습자와 보조 보호자가 자신의 기기 크기(스마트폰, 태블릿, 노트북 등)와 시각적 선호에 맞춰, 화면 상단의 직관적인 버튼으로 **글자 크기**와 **3D 큐브 크기**를 각각 독립적으로 줄이거나 늘릴 수 있다. 학습자는 작은 화면에서도 큐브를 시원하게 키워 회전 동작을 자세히 보거나, 반대로 안내 문구를 시원하게 키워 공식 구호를 또렷하게 읽으며 편안하게 큐브를 맞춘다. 조절한 설정은 기기에 기억되어 다음번 접속 시에도 그대로 유지된다.

## 승인된 범위

- **상단 헤더 우측 상시 조절 컨트롤 바**:
  - 화면 상단 우측에 글자 크기 조절 묶음(`글자 [ − ] [ + ]`)과 큐브 크기 조절 묶음(`큐브 [ − ] [ + ]`) 항상 노출
  - 아이가 쉽게 터치할 수 있는 충분한 터치 영역 및 직관적인 시각 피드백
- **폰트 크기 3~4단계 독립 조절**:
  - 축소(85%), 기본(100%), 확대(115%), 최대(130%) 단계 지원
  - 단계 배율에 따라 안내 텍스트, 공식 구호, 상황/조건 카드, 버튼 텍스트가 조화롭게 비례 확대/축소
  - 최소 단계에서는 `−` 버튼 비활성화, 최대 단계에서는 `+` 버튼 비활성화
  - 폰트 확대 시에도 텍스트가 잘리거나 다른 UI 요소를 침범하지 않는 유연한 반응형 레이아웃
- **3D 큐브 크기 3단계 독립 조절**:
  - 축소(0.8x), 기본(1.0x), 확대(1.2x) 단계 지원
  - 최소 단계에서는 `−` 버튼 비활성화, 최대 단계에서는 `+` 버튼 비활성화
  - 큐브 크기가 변해도 3D 조각 인디케이터(고리, 팝아웃 조각) 및 층 회전 애니메이션의 3차원 좌표 정렬 완벽 유지
  - 큐브 확대/축소 상태에서도 터치/마우스 드래그를 통한 360도 자유 회전 정상 작동
- **설정 영속성 (Local Storage)**:
  - 조절한 글자 크기와 큐브 크기를 브라우저의 `localStorage`에 자동 저장
  - 페이지를 새로고침하거나 새 큐브를 다시 시작해도 마지막 설정 상태 유지
- **독립성 보장**:
  - 글자 크기를 조절해도 큐브 크기는 변하지 않음
  - 큐브 크기를 조절해도 글자 크기는 변하지 않음

## 수용 기준

1. 화면 상단 헤더 우측에 `글자` 크기 조절 버튼(`−`, `+`)과 `큐브` 크기 조절 버튼(`−`, `+`)이 상시 노출된다.
2. `글자 +` 버튼을 누르면 텍스트 크기가 한 단계 커지고, `글자 −` 버튼을 누르면 한 단계 작아진다.
3. 글자 크기가 최소 단계에 이르면 `−` 버튼이 비활성화되고, 최대 단계에 이르면 `+` 버튼이 비활성화된다.
4. `큐브 +` 버튼을 누르면 3D 큐브 크기가 한 단계 커지고, `큐브 −` 버튼을 누르면 한 단계 작아진다.
5. 큐브 크기가 최소 단계에 이르면 `−` 버튼이 비활성화되고, 최대 단계에 이르면 `+` 버튼이 비활성화된다.
6. 큐브 크기를 확대하거나 축소해도 3D 조각 고리(인디케이터)와 조각 내밀기, 층 회전 애니메이션의 위치가 큐브 조각과 정확히 일치한다.
7. 큐브 크기가 변경된 상태에서도 큐브를 드래그하여 시점을 회전하는 상호작용이 매끄럽게 동작한다.
8. 폰트 크기 변경은 큐브 크기에 영향을 주지 않고, 큐브 크기 변경은 폰트 크기에 영향을 주지 않는다.
9. 브라우저를 새로고침하거나 "처음부터 다시"를 눌러도 사용자가 설정한 글자 크기와 큐브 크기가 그대로 유지된다.
10. 영문 기호나 어려운 용어 없이 친숙한 한글("글자", "큐브")과 기호("−", "+")로만 안내된다.

## 확정된 제약

- 기기 하나 안에서 끝난다. 계정, 서버 동기화 없이 브라우저 `localStorage`에만 설정을 저장한다.
- 폰트 및 큐브 크기 조절은 3D 큐브 렌더링 성능이나 큐브 풀이 알고리즘 로직에 일체 영향을 주지 않는다.
- 슬라이더처럼 미세 조작이 어려운 컨트롤 대신, 아이가 쉽게 누를 수 있는 단계별 버튼(`−`, `+`) 방식을 사용한다.
- 모바일 세로 화면에서도 컨트롤 바가 페이지 타이틀이나 단계 배지와 겹치지 않도록 깔끔하게 줄바꿈 또는 정렬된다.

## 연결된 소스

- [guidance-surface](../decisions/guidance-surface.md) — 3D 큐브 표면 및 조각 인디케이터 표시 규칙. 큐브 크기 조절 시에도 이 원칙을 준수한다.
- [ui-composition](../decisions/ui-composition.md) — shadcn Button 및 semantic token 기반의 UI 구성 원칙.
- [PRODUCT.md](../../PRODUCT.md) — 기기 하나 안에서 완결하며 초등학교 5학년이 방해 없이 집중할 수 있는 환경 제공.

## 가정

- CSS Variable과 CSS 3D Transform(`scale`)을 사용하면 기존 3D 큐브 지오메트리 계산(`CUBIE = 54px` 등)을 건드리지 않고도 안전하고 높은 성능으로 크기를 확대/축소할 수 있다.
- 초등학생 및 부모 사용자는 3~4개의 이산적인 단계(작게/보통/크게)만으로도 충분히 만족스러운 시각적 편안함을 얻는다.

## 범위 밖

- 다크 모드/라이트 모드 테마 변경 (별도 기능).
- 큐브 텍스처나 스티커 모서리 둥글기 등 시각 테마 커스터마이징.

## 미룬 지점

- 추후 사용자 피드백에 따라 한 번에 초기화할 수 있는 "크기 초기화(리셋)" 버튼 추가 여부를 검토한다.

## 남은 위험

- 작은 스마트폰 화면에서 폰트 크기와 큐브 크기를 둘 다 최대로 키울 경우, 한 화면에 모든 컨트롤과 큐브가 다 들어오지 않고 세로 스크롤이 길어질 수 있다. 세로 스크롤 시에도 주요 동작 버튼(이전 동작, 다음 동작)의 조작성이 유지되도록 여백과 배치를 점검해야 한다.
