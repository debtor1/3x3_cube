# 흰 십자가까지 안내하기

## 사용자 결과

섞인 큐브를 손에 든 초등학교 5학년이 앱에 자기 큐브의 색을 넣고, 영어 기호 없이 안내를 따라 돌려서, 옆면 색까지 맞은 흰 십자가를 만든다.

## 승인된 범위

- 섞인 큐브의 색 입력
- 입력한 색이 실제 큐브에 있을 수 있는 조합인지 확인
- 입력한 상태를 3D 큐브로 보여주고 자유롭게 돌려볼 수 있게 하기
- 흰 십자가까지의 동작을 하나씩 우리말과 화살표, 회전 애니메이션으로 안내
- 이전 동작과 다음 동작 사이 이동
- 십자가 완성 알림

## 수용 기준

1. 아이가 섞인 큐브의 색을 넣으면 화면의 3D 큐브가 손에 든 큐브와 같은 모습으로 보인다.
2. 실제 큐브에 있을 수 없는 색 조합을 넣으면 다음으로 넘어갈 수 없고, 어느 부분이 잘못됐는지 화면에 드러난다.
3. 안내를 처음부터 끝까지 따라 돌리면 흰 십자가가 만들어지고, 십자를 이루는 네 조각의 옆면 색이 각 면 중앙과 맞는다.
4. 어떤 동작 안내에도 `R`, `U`, `F` 같은 영어 기호가 나타나지 않는다. 우리말 문장과 화살표, 실제로 도는 3D 큐브로만 표현된다.
5. 아이가 손가락이나 마우스로 3D 큐브를 돌려 어느 각도에서든 볼 수 있다.
6. "이전 동작"을 누르면 방금 한 동작을 되돌리는 방법을 알려준다.
7. 십자가가 완성되면 앱이 완성됐음을 알린다.
8. 이미 흰 십자가가 완성된 상태를 넣으면 돌릴 것이 없다고 알린다.

## 확정된 제약

- 1단계는 정렬된 십자가다. 십자 네 조각의 옆면 색이 각 면 중앙과 맞아야 한다. 어긋난 십자가로는 다음 단계인 1층 모서리로 갈 수 없기 때문에 선택의 여지가 없다.
- 동작은 한 번에 하나씩 제시하고 아이가 눌러 넘긴다. 전체 수순을 한꺼번에 펼치지 않는다.
- 기기 하나 안에서 끝난다. 계정, 로그인, 서버 동기화가 없다.
- 광고와 외부 링크를 두지 않는다.

마지막 두 항목은 `PRODUCT.md`의 앱 수준 경계를 그대로 따른 것이다.

## 연결된 소스

- [guidance-surface](../../decisions/guidance-surface.md) — 동작을 어떤 표면으로 보여줄지, 무엇으로 이름 붙일지 규정한다. 3D 큐브와 회전 애니메이션, 영어 기호 배제, 한 동작씩 진행이 여기서 온다.
- [ui-composition](../../decisions/ui-composition.md) — 3D 큐브 바깥의 버튼, 진행 표시, 오류 표시 같은 일반 UI 구성을 규정한다.
- [PRODUCT.md](../../../PRODUCT.md) — 앱 수준 전제. 이 스펙은 관련 경계만 가져왔다.

## 가정

아래는 값싸고 되돌릴 수 있는 기본값이다. 어긋나면 덮어쓴다.

- 입력 검증은 각 색이 아홉 칸인지, 중앙 여섯 색이 서로 다른지, 모서리와 꼭짓점 조각의 색 조합이 실제 큐브에 존재하는지까지 본다. 오타 대부분이 이 수준에서 걸린다고 본다.
- 중앙 여섯 칸은 고정이므로 아이가 칠하지 않는다.
- 앱은 아이가 안내대로 돌렸다고 믿는다. 매 동작 뒤 3D 큐브가 지금 있어야 할 모습을 보여주므로, 아이가 자기 큐브와 다르다고 느끼면 색을 다시 넣는 것으로 회복한다.
- 완성 알림은 간단한 축하 표시로 둔다.

## 범위 밖

- 2단계부터 7단계까지의 안내 — 1단계가 실제로 통하는지 먼저 확인한다.
- 뱃지, 미니게임, 복습 퀴즈 — 단계가 쌓인 뒤에야 의미가 생긴다.
- 기록 저장과 보호자 진도 화면 — 단계가 하나뿐이라 볼 진도가 없다.
- 배속 조절 — 동작을 하나씩 끊어 보므로 첫 판에서는 필요가 드러나지 않았다.
- 최근 세 동작을 한꺼번에 되돌리는 실수 복구 모드 — "이전 동작"으로 한 칸씩 되돌리는 것에서 시작한다.

## 미룬 지점

- **3D 렌더링 방식** — 구현에서 정한다. 이 스펙은 관찰 가능한 행동만 정하고 기술을 고르지 않는다.
- **회전 패리티 검증** — 위 가정의 검증 수준으로 시작한다. 그때까지는 검증을 통과한 입력을 풀 수 있는 상태로 다룬다(잠정). 검증을 통과했는데 안내대로 돌려도 십자가가 나오지 않는 사례가 나오면 이 지점을 다시 연다.

## 남은 위험

- 마흔여덟 칸을 색칠하는 일이 5학년에게 지루하거나 어려울 수 있다. 첫 관문에서 아이가 떨어질 위험이 여기 있고, 실제로 아이가 해봐야만 드러난다.
- 성공 신호인 "안내를 펼친 횟수의 감소"는 기록 저장이 범위 밖이라 이번에는 측정되지 않는다.
- 3D 큐브를 돌려 자기 큐브와 각도를 맞추는 조작이 5학년에게 자연스러운지 아직 확인되지 않았다.
