# 큐브 사진 촬영 및 업로드를 통한 색상 자동 입력

## 개요 (User-Visible Outcomes)

- 사용자는 큐브의 색을 54번 일일이 클릭해서 칠하지 않고, 큐브 사진 2장을 찍거나 올려서 6개 면의 색상을 한 번에 자동 입력할 수 있다.
- 외부 AI API 비용 및 리소스 보호를 위해, **구글 계정(`debtor11@gmail.com`)으로 로그인하여 인증된 사용자만** 해당 기능을 사용할 수 있다.
- 비로그인 사용자나 다른 계정으로 로그인한 사용자에게는 로그인 및 권한 안내가 표시되며, 기존 수동 색칠 및 큐브 풀이 가이드는 로그인 없이 누구나 자유롭게 이용할 수 있다.
- 1번 사진(위-앞-오른쪽 3면)과 2번 사진(아래-뒤-왼쪽 3면)을 순서대로 등록하면 AI가 큐브의 색상을 인식하여 기존 전개도에 자동으로 채운다.
- 사진 인식 후에도 기존 전개도에서 잘못 인식된 칸을 터치해 손쉽게 직접 수정할 수 있다.

## 승인된 범위 (Approved Scope)

- **인증 및 접근 제어 (NextAuth / Auth.js)**:
  - 구글 로그인 연동 (`Google Provider`).
  - 허용 계정 화이트리스트: `debtor11@gmail.com`만 사진 분석 기능 이용 허용.
  - 헤더 또는 사진 입력 진입 지점에 로그인/로그아웃 버튼 및 현재 로그인 상태 표시.
  - 비로그인 상태에서 "사진으로 색상 채우기" 클릭 시 구글 로그인 모달/버튼 안내.
  - 다른 구글 계정으로 로그인 시 "지정된 관리자(`debtor11@gmail.com`)만 이용할 수 있어요" 안내 및 기능 제한.
  - 서버 API Route(`/api/cube/recognize`)에서 세션 검증을 수행하여 비인증 또는 비인가 요청 시 `401 Unauthorized` / `403 Forbidden` 차단.
- **사진 입력 진입점**:
  - 초기 색상 입력 화면에서 "사진으로 색상 채우기" 버튼 제공.
- **2단계 대각선 사진 등록 모달/인터페이스**:
  - 1번 사진: 흰색(위), 초록색(앞), 빨간색(오른쪽) 중심면이 보이는 대각선 앵글 안내 및 등록(카메라 촬영 또는 갤러리/파일 업로드).
  - 2번 사진: 노란색(아래), 파란색(뒤), 주황색(왼쪽) 중심면이 보이는 대각선 앵글 안내 및 등록(카메라 촬영 또는 갤러리/파일 업로드).
- **AI 색상 인식 연동**:
  - Vercel AI Gateway(`AI_GATEWAY_API_KEY`)를 통해 Vision AI 모델(`google/gemini-2.5-flash`)로 2장의 이미지를 전송하고 54개 칸의 색상(흰색, 초록색, 빨간색, 노란색, 주황색, 파란색)을 JSON으로 추출.
- **결과 확인 및 보정 연동**:
  - 추출된 54개 칸 색상을 기존 전개도(`ColorInput`) 상태에 자동 반영.
  - 조명이나 반사로 오인식된 칸이 있을 경우, 기존 전개도 편집 기능을 통해 사용자가 즉시 수정 가능.
  - 큐브 유효성 검사 규칙(각 색상 9개, 물리적으로 가능한 큐브 상태)과 즉각 연동되어 유효하지 않은 경우 안내 표시.
- **오류 및 실패 안내**:
  - 사진이 흐리거나 인식이 실패했을 때 사용자 친화적인 우리말 오류 메시지 표시 및 재시도 유도.

## 관찰 가능한 수용 기준 (Observable Acceptance Criteria)

1. **인증 상태별 진입 제어**:
   - 비로그인 사용자가 "사진으로 색상 채우기"를 누르면 "구글 로그인 후 이용할 수 있어요" 안내와 함께 [구글로 로그인] 버튼이 표시된다.
   - `debtor11@gmail.com`이 아닌 다른 구글 계정으로 로그인한 경우 "현재 debtor11@gmail.com 계정만 사진 자동 입력을 사용할 수 있어요"라는 경고가 표시되고 사진 등록이 제한된다.
   - `debtor11@gmail.com`으로 로그인한 경우 사진 등록 및 AI 분석 UI가 정상 활성화된다.
   - 일반 학습 기능(손으로 큐브 색칠하기, 7단계 해법 가이드)은 로그인 여부와 무관하게 모든 사용자가 아무런 제약 없이 이용할 수 있다.
2. **서버 사이드 인가 방어**:
   - `/api/cube/recognize` API는 세션이 없으면 `401`, 이메일이 `debtor11@gmail.com`이 아니면 `403`을 반환하며 AI API를 호출하지 않는다.
3. **사진 등록 및 미리보기**:
   - 인가된 사용자가 1번 사진과 2번 사진을 각각 카메라로 촬영하거나 앨범에서 선택하면 해당 사진의 썸네일 미리보기가 표시된다.
   - 두 장의 사진이 모두 등록되기 전까지는 "AI로 색상 분석하기" 버튼이 비활성화된다.
   - 등록한 사진을 삭제하고 다시 찍거나 다른 사진으로 교체할 수 있다.
4. **AI 색상 분석 및 전개도 반영**:
   - 두 장의 사진 등록 후 분석 버튼을 누르면 로딩 상태(스피너 및 "큐브 색상을 분석하고 있어요..." 안내)가 표시된다.
   - 분석이 완료되면 모달이 닫히며 54개 칸이 사진에서 추출된 색상으로 자동 채워진다.
5. **오인식 수정 및 유효성 검사**:
   - AI로 입력된 상태에서도 사용자가 팔레트 색을 고르고 칸을 눌러 언제든 수정할 수 있다.
   - 유효하지 않은 큐브 상태일 때 기존의 친절한 오류 안내가 즉시 노출된다.
6. **네트워크 및 API 실패 처리**:
   - 네트워크 연결 오류, API 키 누락, 또는 AI 분석 실패 시 "사진을 분석하지 못했어요. 다시 찍거나 직접 색을 칠해주세요."라는 안내 메시지가 나타나고 사용자는 작업을 중단 없이 이어갈 수 있다.

## 합의된 제약사항과 이유 (Settled Constraints & Rationale)

- **NextAuth (Auth.js) 기반 구글 로그인**:
  - 별도의 데이터베이스 인프라 없이도 Google Client ID/Secret만으로 가볍고 표준적인 세션 기반 인증을 구현할 수 있다.
- **특정 계정(`debtor11@gmail.com`) 화이트리스트 접근 제어**:
  - Vercel AI Gateway 비용이 발생하는 비전 모델 호출을 보호하기 위해, 지정된 관리자 1인에게만 사진 인식 기능을 오픈한다.
- **학습 코어 루프 보호**:
  - `PRODUCT.md`의 "기기 하나 안에서 계정 없이 완결한다"는 원칙을 일반 학습 루프(수동 칠하기 및 풀이)에서는 엄격히 유지하고, 오직 외부 AI 비용이 드는 기능에 대해서만 선택적 인증 게이트를 둔다.
- **대각선 2장 촬영 방식**:
  - 6회 반복 촬영의 번거로움을 줄이고 단 2번의 촬영으로 6개 면 전체를 커버한다.
- **표준 브라우저 파일/카메라 인풋(`input[type="file"]`) 사용**:
  - 권한 문제나 브라우저 호환성 제약 없이 모바일 기본 카메라와 앨범 업로드를 안정적으로 지원한다.
- **Vercel AI Gateway 및 `google/gemini-2.5-flash` 채택**:
  - `.env.local`의 `AI_GATEWAY_API_KEY`를 활용하며 멀티모달 이미지 인식 속도와 3x3 그리드 구조화 출력이 우수하다.

## 가정사항 (Assumptions)

- 사용자가 구글 클라우드 콘솔에서 OAuth Client ID 및 Client Secret을 발급받아 `.env.local`에 설정할 수 있다 (`AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `AUTH_SECRET`).
- 촬영되는 큐브는 표준 색상 배치를 따르는 3x3 큐브이다.

## 범위 밖 영역과 이유 (Off-limits Areas & Why)

- **일반 회원의 회원가입/로그인 및 데이터 클라우드 동기화**:
  - 학생들의 일반 큐브 맞추기 학습 경험은 계정 없이 즉시 이용 가능해야 한다는 제품 핵심 원칙을 유지하기 위함.
- **웹캠 실시간 AR 트래킹**:
  - 기술적 복잡도를 낮추고 직관적이고 안정적인 2장 사진 업로드 경험 제공.

## 남은 위험 (Remaining Risks)

- **OAuth 리디렉션 URI 및 환경변수 설정 누락**:
  - 구글 로그인 설정 시 로컬/배포 URL 승인 및 환경변수 누락 가능성.
  - *완화책*: 환경변수가 누락된 경우 콘솔 및 개발 환경에서 명확한 안내를 제공.
- **특수 조명/반사광으로 인한 색상 오인식**:
  - *완화책*: 분석 완료 후 즉시 전개도에 시각화하여 보여주고 수동 수정이 즉각 가능하도록 함.
